Inferential statistics

A number of inferential statistics concerning the Covid-19 in Canada.

1. Cases forecast for years 2020-2022

Used the SARIMAX model for its simplicity and interpretability for time series data.
Parameter tuning was done with pmarima.arima.auto_arima, seasonality chosen by trial-and-error.
No exogenous values were used.
Final model: SARIMAX(1, 1, 0)x(2, 0, [1], 7).

2. Deaths forecast for years 2020-2022

Used the SARIMAX model for its simplicity and interpretability for time series data.
Parameter tuning was done with pmarima.arima.auto_arima, seasonality chosen by trial-and-error.
No exogenous values were used.
Final model: SARIMAX(2, 0, 1).

3. Case fatality rate forecast for years 2020-2022

Used the SARIMAX model for its simplicity and interpretability for time series data.
Parameter tuning was done with pmarima.arima.auto_arima, seasonality chosen by trial-and-error.
Data about vaccine doses, people vaccinated, tests and booster doses were used as exogenous values..
Final model: SARIMAX(0, 2, 1)x(0, 0, 1, 7).
